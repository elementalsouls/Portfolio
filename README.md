# Sachin Sharma — Portfolio

Personal portfolio site. **Offensive Security Engineer · AI-Driven Security Automation.**
Creator of [Claude-BugHunter](https://github.com/elementalsouls/Claude-BugHunter) and [Claude-OSINT](https://github.com/elementalsouls/Claude-OSINT).

## Stack
Single self-contained `index.html` — HTML + CSS + vanilla JS, no build step, no dependencies to install.
Fonts (Fraunces / Hanken Grotesk / JetBrains Mono) load from Google Fonts; everything else is inline (SVG icons, styles, scripts).

## Run locally
Open `index.html` in a browser. That's it.

## Deploy (GitHub Pages)
Settings → Pages → Source: `main` branch, `/root`. Serves at `https://elementalsouls.github.io/Portfolio/`.

## Edit
All content lives in `index.html`. Update text/metrics inline; colors and type are CSS variables in the `:root` block at the top of the `<style>` tag.
